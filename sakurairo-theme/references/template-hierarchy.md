# 页面模板与布局参考

## 标准页面类型

| 页面类型 | 模板 | 说明 |
|---|---|---|
| 首页 | `index.php` | 组件驱动的首页 |
| 单篇文章 | `single.php` | 文章详情页 |
| 独立页面 | `page.php` | 静态页面 |
| 归档页 | `archive.php` | 分类/标签/日期归档 |
| 作者页 | `author.php` | 作者文章列表 |
| 搜索结果 | `search.php` | 搜索结果展示 |
| 404 页面 | `404.php` | 页面未找到 |
| 友情链接 | 标准链接管理器 | 通过 WP 链接管理功能 |

## 文章列表样式

### 缩略图列表（默认）
传统博客布局，显示特色图片缩略图、标题、摘要和元信息。

### 卡片式列表
现代卡片布局，在主题选项中切换。

## 单篇文章布局

单篇文章页面包含以下区域（按顺序）：
1. **文章头部** - 标题、作者、分类、日期、阅读时间
2. **AI 摘要** - 如已生成，显示 AI 摘要框
3. **文章目录** - 如开启，根据标题自动生成
4. **正文内容** - WordPress 编辑器内容
5. **文章底部** - 许可协议、打赏、作者信息、标签、更新日期

## 首页组件

首页由可排序的组件组成（在主题选项中配置顺序）：
1. **静态页面** - 嵌入一个页面的内容
2. **展示区** - 精选/推荐内容
3. **文章列表** - 主博客流
