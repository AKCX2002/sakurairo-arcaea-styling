# 中文技术文档排版规范

## 来源

整合自 `tech-doc-style-chinese` 技能，适用于 Sakurairo Arcaea 博客的中文技术文章。

## 核心排版规则

### 1. 中英文/数字间距

中文与英文/数字之间加空格：

```
❌ 支持JSON格式和XML格式
✅ 支持 JSON 格式和 XML 格式

❌ 版本号为1.2.3，发布于2024年
✅ 版本号为 1.2.3，发布于 2024 年
```

**例外**：代码字面量、JSON key、URL、API 路径、数据库字段名等机器可读标识符不应用空格规则。

### 2. 引号

中文正文中使用「」而非 ""：

```
❌ 这是一个"示例"说明
✅ 这是一个「示例」说明
```

### 3. 避免直接称呼

```
❌ 您可以通过以下步骤完成配置。
✅ 通过以下步骤完成配置。

❌ 你好同学，欢迎使用本产品。
✅ 欢迎使用本产品。
```

### 4. 状态词翻译

避免机械翻译 English HTTP/API 状态词：

| English | 错误 | 正确 |
|---------|------|------|
| Success | 成功 | 请求已完成 / 操作成功 |
| Invalid | 无效的 | 参数格式不正确 |
| Bad Request | 坏请求 | 请求参数有误 |
| Forbidden | 被禁止的 | 无访问权限 |
| Not Found | 没有找到 | 资源不存在 |

### 5. 禁用词汇

```
赋能  抓手  闭环  打通  沉淀  链路  颗粒度
生态  矩阵  倒逼  落地  变现  复盘  对齐  拉齐
```

这些词在中文技术正文中视为错误。

### 6. 常见错别字

| 错误 | 正确 |
|------|------|
| 阀值 | 阈值 |
| 登陆 | 登录 |
| 布署 | 部署 |
| 配制 | 配置 |
| 起用 | 启用 |
| 反回 | 返回 |
| 回朔 | 回溯 |
| 标示 | 标识 |
| 帐户 | 账户 |
| 帐号 | 账号 |
| 截止 目前 | 截至 目前（时间截止点用「截至」） |

### 7. 术语大小写

```
❌ id  http  url  json  api  ai  JS  Js  H5  llm  aigc  rag
✅ ID  HTTP  URL  JSON  API  AI  JavaScript  HTML5  LLM  AIGC  RAG
```

## 内容类型规范

### API 参数表

```markdown
| 参数名    | 类型   | 必填 | 说明                          |
|-----------|--------|------|-------------------------------|
| user_id   | string | 是   | 用户唯一标识，长度 8–32 位    |
| page      | int    | 否   | 页码，从 1 开始，默认为 1     |
```

### 错误码表

```markdown
| 错误码 | 说明                         | 处理建议                              |
|--------|------------------------------|---------------------------------------|
| 40001  | 缺少必填参数 `user_id`       | 检查请求体是否包含 `user_id` 字段     |
| 40301  | 当前账号无访问该资源的权限   | 联系管理员确认角色权限配置            |
```

## 与 Sakurairo 文章的配合

在 *.arcaea-article-content* 中应用上述规则：
- 代码块内的标识符**不**适用 CJK 空格规则
- 技术术语首次出现时使用正确大小写（如 CMake、FreeRTOS、STM32）
- 避免在博客正文中使用「您」——嵌入式技术文章以「开发者」为隐含读者
