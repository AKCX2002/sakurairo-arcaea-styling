# 主题选项参考（功能使用指南）

主题使用 Codestar Framework 构建选项面板。所有设置在 WordPress 后台「主题选项」页面中配置。

## 快速配置速查表

### 全局外观设置

| 功能 | 配置位置 | 说明 |
|---|---|---|
| 主题主色 | 主题选项 → 全局设置 | 网站主色调 |
| 主题强调色 | 主题选项 → 全局设置 | 强调/匹配颜色 |
| 暗黑模式色 | 主题选项 → 全局设置 | 暗黑模式下的主题色 |
| 全局字体粗细 | 主题选项 → 全局设置 | 如 400(常规)、700(粗体) |
| 网站图标 | 主题选项 → 全局设置 | Favicon 图标 URL |
| Google 字体 | 主题选项 → 全局设置 | 配置字体 API 域名 |
| Font Awesome | 主题选项 → 全局设置 | 图标库 CDN 地址 |
| 自定义 CSS | 主题选项 → 全局设置 | 写入额外样式代码 |
| 纪念模式 | 主题选项 → 全局设置 | 全站灰度显示 |
| PHP 错误级别 | 主题选项 → 全局设置 | 控制错误显示 |

### 首页封面

| 功能 | 配置位置 | 说明 |
|---|---|---|
| 视频封面 | 主题选项 → 首页封面 | 上传或链接封面视频 |
| 封面图片 | 主题选项 → 首页封面 | 静态封面图片 |
| 全屏模式 | 主题选项 → 首页封面 | 封面占满全屏 |
| 直播模式 | 主题选项 → 首页封面 | 直播流转发 |
| 循环播放 | 主题选项 → 首页封面 | 视频循环播放 |

### 首页组件

| 功能 | 配置位置 | 说明 |
|---|---|---|
| 组件排序 | 主题选项 → 首页设置 | 拖拽排列首页各区域顺序 |
| 文章区域图标 | 主题选项 → 首页设置 | Font Awesome 图标名 |
| 文章区域标题 | 主题选项 → 首页设置 | 如「文章列表」「最新文章」 |
| 分页样式 | 主题选项 → 首页设置 | AJAX 加载或传统翻页 |

### 文章与页面

| 功能 | 配置位置 | 说明 |
|---|---|---|
| 文章底部功能 | 主题选项 → 页面设置 | 显示许可协议、作者等信息 |
| 默认许可协议 | 主题选项 → 页面设置 | 文章默认 CC 协议类型 |
| 自动生成目录 | 主题选项 → 页面设置 | 根据标题自动生成 TOC |
| 内容样式 | 主题选项 → 页面设置 | Sakura 风格 / GitHub 风格 |
| 实时搜索 | 主题选项 → 页面设置 | 开启 AJAX 即时搜索 |

### 页脚内容

| 功能 | 配置位置 | 说明 |
|---|---|---|
| 一言显示 | 主题选项 → 页脚设置 | 随机显示一句话 |
| 自定义文本 | 主题选项 → 页脚设置 | 自定页脚文字内容 |
| 加载统计 | 主题选项 → 页脚设置 | 显示耗时/查询数/内存 |
| CDN 赞助 | 主题选项 → 页脚设置 | 显示又拍云等信息 |
| 樱花图标 | 主题选项 → 页脚设置 | 底部樱花 SVG |

### CDN / 性能

| 功能 | 配置位置 | 说明 |
|---|---|---|
| 共享库来源 | 主题选项 → CDN 设置 | 本地/ CDN 加载 |
| 核心库来源 | 主题选项 → CDN 设置 | 本地/ CDN 加载 |
| CDN 地址 | 主题选项 → CDN 设置 | jsDelivr 或自定义 |
| 视觉资源路径 | 主题选项 → CDN 设置 | 主题视觉资源 CDN |

### 社交集成

| 功能 | 配置位置 | 说明 |
|---|---|---|
| Gravatar 代理 | 主题选项 → 社交/集成 | 国内 Gravatar 镜像 |
| 图片上传服务 | 主题选项 → 社交/集成 | Imgur/SM.MS/Chevereto/Lsky |
| Bilibili | 主题选项 → 社交/集成 | B站 API 集成设置 |
| Steam | 主题选项 → 社交/集成 | Steam API Key |
| 验证码 | 主题选项 → 社交/集成 | CAPTCHA/Turnstile/Vaptcha |

### AI 功能

| 功能 | 配置位置 | 说明 |
|---|---|---|
| ChatGPT API Key | 主题选项 → AIGC 管理 | 配置 OpenAI API Key |
| AI 模型选择 | 主题选项 → AIGC 管理 | 选择使用的模型 |
| 文章 AI 摘要 | API 触发 | 为文章生成智能摘要 |
| 名词 AI 注释 | API 触发 | 为文章生成术语注释 |

### 更新

| 功能 | 配置位置 | 说明 |
|---|---|---|
| 更新源 | 主题选项 → 更新设置 | GitHub / 又拍云 / 官方 |
| 更新频道 | 主题选项 → 更新设置 | 选择构建频道 |
